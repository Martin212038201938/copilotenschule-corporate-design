# Accordion

FAQ und aufklappbare Details auf Basis von `<details>`/`<summary>` – funktioniert ohne JavaScript und ist tastaturbedienbar. Der Aufrufer liefert `items` mit `question`, `answer`, optional `open`.

- Fragen so formulieren, wie Kunden sie stellen („Brauchen wir dafür eine Copilot-Lizenz?“) – das hilft auch bei Suchmaschinen und KI-Antworten.
- Antworten beginnen mit der direkten Antwort im ersten Satz.
- Maximal acht Einträge pro Block.
