# SlideLayouts

Die Folientypen der verbindlichen PowerPoint-Vorlage `Copilotenschule_Vorlage1.potx` im Überblick (16:9). Weiß ist Standard, Blau nur für den Kapiteltrenner. Maße, Schriftgrade und Theme-Farben stehen im Abschnitt „PowerPoint“.

- Titelfolie: Primärlogo oben links, Dachzeile, Titel, Firmenname in roter Dachzeilen-Schrift darunter, großer Streifen-Kick rechts unten.
- Kapiteltrenner: blau, weiße Startnummer, Kick mit weißem ersten Streifen.
- Inhaltsfolien: Kopf-Winkel in der oberen linken Ecke, Streifen laufen über die ganze Folienbreite, Titel rechts neben dem Winkel, Logo klein unten rechts.
- Kennzahl und Zitat: ohne Kopf-Winkel, dafür großer Streifen-Kick rechts unten.
- Abschluss: Kopf-Winkel mit Titel, Kontakt, Logo unten links, Kick rechts unten.
- Keine Fußzeile, keine Foliennummern.
