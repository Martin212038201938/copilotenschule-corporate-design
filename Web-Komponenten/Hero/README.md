# Hero

Einstiegsbühne einer Seite oder Landingpage. Der Aufrufer liefert `title` (max. 8 Wörter), `lead` (ein Satz Nutzen), `eyebrow` und `actions` (eine `primary` plus optional eine `inverse`/`outline`).

- `tone="brand"` (Standard): blaue Fläche, weiße Schrift, Kick mit weißem ersten Streifen – der Martini-nahe Auftritt.
- `tone="light"`: für Unterseiten und Wissensartikel.
- Der Streifen-Kick läuft rechts unten aus der Fläche. Keine Fotos hinter den Streifen.
- Headline sagt das Ergebnis für den Kunden, nicht das Produkt („Copilot, der im Alltag ankommt“ statt „Unser Copilot-Training“).
