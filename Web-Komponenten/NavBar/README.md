# NavBar

Kopfnavigation. Der Aufrufer liefert `logoSrc` (Primärlogo auf `tone="light"`, Negativlogo auf `tone="brand"`), `links` mit `active` für die aktuelle Seite und `cta` für genau eine Hauptaktion.

- Maximal sieben Links, kurze Substantive („Trainings“, „Workshops“, „Copilot Wissen“).
- Aktiver Link: roter Unterstrich; Hover: türkiser Unterstrich.
- Logo nie kleiner als 36px hoch in der Navigation; Schutzraum links mindestens `space-4`.
- Mobil (&lt; 720px) brechen die Links unter das Logo; ein Burger-Menü ergänzt die Website selbst.
