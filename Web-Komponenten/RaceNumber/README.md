# RaceNumber

Die Startnummer: ein kreisrundes Nummernschild wie auf klassischen Rallye- und Tourenwagen. Der Aufrufer liefert die Ziffern (max. 3 Zeichen), `size` in px, `tone` und für Screenreader `label`.

- Einsatz: Modulnummern, Agenda-Punkte, Kapitelnummern auf Folien, Schrittfolgen.
- `plate` (weiß mit blauem Ring) auf Blau und auf Fotos; `blue` als Standard auf Hell; `red` nur für das hervorgehobene Element.
- Immer zweistellig schreiben („01“ statt „1“) – das ist der Startnummern-Look.
- Nicht: Buchstaben, Icons, Emojis in der Startnummer.
