# Eyebrow

Dachzeile über Headlines in Aptos Narrow Bold Italic, Versalien, mit einem geschrägten Mini-Streifen davor. Der Aufrufer liefert den Text (2–4 Wörter), auf Blau `tone="inverse"`.

- Funktion: Einordnung („Modul 03 · Outlook“, „Für Führungskräfte“). Nie ganze Sätze.
- Farbe: `accent` auf Hell, `brand-turquoise` auf Blau und im Nacht-Theme.
- Rallye-Vokabular hier am sparsamsten einsetzen: „Etappe 02“ ist ok, eine Kette von Motorsport-Begriffen nicht.
