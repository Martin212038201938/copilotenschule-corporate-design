# Tag

Kurzes Merkmal in Versalien (Stil `label`). Der Aufrufer liefert den Text und `tone`.

- `default`: Format und Rahmen („Live“, „Inhouse“, „Remote“).
- `brand`: Zielgruppe („Führungskräfte“).
- `turquoise`: Neuheiten, Aktualität („Neu“).
- `accent`: nur Knappheit mit echtem Anlass („Wenige Plätze“). Nie als Dauerzustand.
