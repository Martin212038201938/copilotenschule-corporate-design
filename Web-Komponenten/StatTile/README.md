# StatTile

Kennzahl in Startnummern-Typografie (Aptos Narrow Bold Italic) mit roter Kopflinie. Der Aufrufer liefert `value`, `label` und optional `note` (Quelle, Stand).

- Nur belegte Zahlen, mit Quelle oder Stand in `note`, wenn sie sich ändern können.
- Im 4er-Grid als Vertrauensleiste; `tone="brand"` für eine einzelne Kennzahl auf Folien.
- Zahlen auf Website, Folien und Profilen einheitlich halten – eine Quelle der Wahrheit.
