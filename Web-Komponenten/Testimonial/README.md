# Testimonial

Kundenstimme mit kurzem Streifenband darüber. Der Aufrufer liefert `quote` (freigegeben, wörtlich), `name`, `role`, `company`.

- Nur echte Zitate mit Freigabe. Kürzen ist erlaubt, Umschreiben nicht.
- Zitat in `display`-Schrift, 1–3 Sätze. Keine Anführungszeichen-Grafiken, keine Sterne-Icons.
- Auf Folien: ein Zitat pro Folie, mittig links, `StripeRule short` darüber.
