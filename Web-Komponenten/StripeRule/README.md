# StripeRule

Waagerechtes Dreierband aus den Logofarben als Trenner. Der Aufrufer liefert nur `tone` und optional `short` (72px, über Zitaten und Kennzahlen).

- Volle Breite: als Abschluss eines Hero-Bands, über dem Footer, als Kopfleiste von Folien.
- `short`: Akzent über Zitaten, Tabellen, Zwischenüberschriften.
- Balkenstärke 8px, Abstand 4px – halbe Streifenstärke wie im Logo (`stripe-gap`).
- Nicht: senkrecht stellen, als Rahmen um Karten, mehr als ein volles Band pro Bildschirmhöhe.
