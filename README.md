# Copilotenschule – Corporate Design

Alle Grundlagen für Website, PowerPoint und Unterlagen der Copilotenschule. Inspiriert vom klassischen Rallye- und Tourenwagensport, eigenständig umgesetzt.

## Inhalt

| Ordner | Was |
|---|---|
| `Handbuch/` | Corporate Design Handbuch als Word-Dokument – alle Regeln an einem Ort, auch als Grundlage für Präsentationen |
| `PowerPoint/` | `Copilotenschule_Vorlage1.potx` – die verbindliche Vorlage für alle Präsentationen |
| `Logos/` | Alle Logovarianten als SVG und PNG, Streifenmotiv, Original-Logoblatt des Designers (`Quelle/`) |
| `Design-Tokens/` | Farben, Schrift, Abstände, Radien als `tokens.json` und `tokens.css` |
| `Richtlinien/` | Markenhandbuch, Tonalität und PowerPoint-Regeln als Markdown |
| `Web-Komponenten/` | React-Bausteine (`bundle.js`, `bundle.css`, Typen) mit Richtlinie je Baustein |
